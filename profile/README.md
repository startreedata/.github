# StarTree

StarTree builds a real-time analytics platform powered by Apache Pinot. StarTree Cloud provides a fully managed service with enterprise capabilities for ingesting, querying, and managing streaming and lakehouse data.

## Explore StarTree

- [Website](https://startree.ai/) — Learn about our platform and use cases.
- [Documentation](https://docs.startree.ai/) — Find guides, API references, and release notes.
- [Community](https://startree.ai/community/) — Connect with the real-time analytics community.
- [Support](https://startree.ai/support/) — Learn how to get help from StarTree.

## Open source

- [Apache Pinot](https://pinot.apache.org/) — The open-source database powering StarTree.
- [MCP Server for Apache Pinot](https://github.com/startreedata/mcp-pinot) — Connect AI assistants to Apache Pinot.

## Pinot clients

| Language / interface | Client |
| --- | --- |
| Java | [Apache Pinot Java client](https://github.com/apache/pinot/tree/master/pinot-clients/pinot-java-client) |
| JDBC | [Apache Pinot JDBC client](https://github.com/apache/pinot/tree/master/pinot-clients/pinot-jdbc-client) |
| Python | [pinot-dbapi](https://github.com/startreedata/pinot-dbapi) — DB-API and SQLAlchemy support |
| Go | [pinot-client-go](https://github.com/startreedata/pinot-client-go) |
| Ruby | [ruby-pinot-client](https://github.com/startreedata/ruby-pinot-client) |
| ODBC | [pinot-odbc-driver](https://github.com/startreedata/pinot-odbc-driver) |

See the [Apache Pinot client documentation](https://docs.pinot.apache.org/build-with-pinot/connectors-clients-apis/client-libraries) for connection guides and usage examples.
